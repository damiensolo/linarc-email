# Forks

A library component copied here because the change it needs is risky for production use or still experimental (CLAUDE.md › Changing the design system). One folder per component: `src/forks/<Name>/<Name>.vue`, imported as `~/forks/<Name>/<Name>.vue`.

- The header comment names the source path in `../linarc-design-components` and summarises the diff.
- Every fork has a row in `../linarc-design-components/PRPs/prototype-changes/README.md` with status `fork`.
- A fork is temporary: once the change is accepted it goes into the library and the fork is deleted.
